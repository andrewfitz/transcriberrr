# Realtime wire traces

These JSONL excerpts contain server events captured on loopback using synthetic speech. The native traces omit the resume credential.

- The committed OpenAI turns used the published `transcribeTurn` example with Node.js 26.13.1, `openai` 7.62.0, and `ws` 8.23.0 against Apple SpeechTranscriber. It covers setup, an empty commit, buffer clear, and two turns. The second commit points to the first item as its predecessor. [Captured events](openai-committed.jsonl) · [OpenAI transcription guide](https://developers.openai.com/api/docs/guides/realtime-transcription)
- The live OpenAI turns used the same Node.js client against Parakeet Unified. Two 1.8-second turns completed. The paced third turn emitted two deltas before commit, then reached the recognition queue limit. The commit acknowledged the same item ID after the terminal failure. A paced 2.4-second follow-up emitted a delta before commit and completed with the same item ID. [Longer exercise](openai-live.jsonl) · [Paced completion](openai-live-short.jsonl)
- The native reconnect used reference client version 1 with Python 3.15.2 and `websockets` 15.0.1 against Apple SpeechTranscriber. It registers two isolated tracks, starts the second track at frame 28,800, and reconnects mid-turn with both tracks at frame 127,200. A missing interval on the second track is reported as `[172800, 196800)`. The first track keeps its original item ID through reconnect and finalization. The input excerpt preserves send order and replaces each audio payload with its decoded frame count. The second track briefly captions crosstalk while the newly joined mic pair is still uncalibrated. [Captured events](native-reconnect.jsonl) · [Input excerpt](native-input.jsonl) · [Reference client](../../scripts/realtime-client.py)
